# Blood-Bank-Management-System
A Blood Bank Management System built using Python, Tkinter, and SQL Server to manage blood units, hospitals, requests, deliveries, and vans with an easy-to-use GUI.
Project Overview
The Blood Bank Management System is designed to manage blood bank operations such as blood units, hospitals, requests, deliveries, and vans using SQL Server and a simple GUI.
Objectives
•	Store and organize blood bank data. 
•	Manage blood donations and requests. 
•	Allow users to enter data easily without SQL knowledge. 
Main Features
•	Add and view blood types and blood units. 
•	Manage hospitals and blood requests. 
•	Track deliveries and vans. 
•	Search and delete records. 
Requirements
•	Connect to SQL Server database. 
•	Simple and user-friendly GUI. 
•	Data validation and error handling. 
•	Fast and reliable performance.
